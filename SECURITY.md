# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| v1 | Yes |

Security fixes are released as new immutable semantic versions. Published
version tags are never moved or reused. The `stable-release` tag remains a
convenience pointer to the latest cross-platform binaries and is not a version
identifier.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use
[GitHub private vulnerability reporting](https://github.com/matveynator/chicha-isotope-map/security/advisories/new)
and include the affected version, a minimal reproduction, the expected impact,
and any suggested remediation.
